# LeetCode Solutions

Welcome to my LeetCode Solutions repository! 🚀

This repository contains my personal solutions to various LeetCode problems. The solutions are primarily written in C++ (and Python/other languages), aiming for optimal time and space complexity. 

## 📂 Repository Structure

To make it easy to find solutions, the repository is organized by topics and data structures. Some of the main categories include:

- **Array**
- **Dynamic Programming**
- **Graph Theory**
- **Tree & Binary Search Tree**
- **Hash Table**
- **Sorting & Searching**
- **String**
- ... and many more!

Each folder contains the source code for the problems associated with that specific topic.

## 🛠️ Tech Stack
- **C++** (Primary)
- **Python** (Secondary)
- **JavaScript/HTML** (Dashboard included in the repository)

## 📈 Tracking Progress
A custom dashboard is included in this repository (`dashboard_builder.py`, `index.html`, `index.js`) to help visualize and track problem-solving progress.
